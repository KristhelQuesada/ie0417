Detailed Description

Estructura que representa un contacto en una lista enlazada.

Esta estructura puede utilizarse tanto para representar un único contacto como para formar parte de una lista enlazada de contactos. Si se usa como contacto individual, el miembro siguiente debe inicializarse como nullptr.

Detailed Description

Clase que implementa una estructura de datos tipo tabla hash.

Esta clase permite almacenar objetos de tipo Contacto utilizando una clave tipo string. Internamente, utiliza un arreglo de listas enlazadas para manejar colisiones mediante encadenamiento.

## Repository Set-Up
You can either clone it via HTTPS option or SSH Key if you have one, otherwise you'll need to create it first. If you don't have an SSH Key check the following video to learn how to create one: [Creat SSH key in Ubuntu to access Github via SSH](https://www.youtube.com/watch?v=EoLrCX1VVog).

__HTTPS__
``` sh
git clone https://github.com/KristhelQuesada/ie0417.git
```
__SSH Key__
``` sh
git clone git@github.com:KristhelQuesada/ie0417.git
```
